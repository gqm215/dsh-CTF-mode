## 4. 阻塞与诚实边界

- 需要实例的题型（pwn/web 交互/VPN 题）当前无法验收：平台节点池离线，错误由平台给出（`no_healthy_node` / `dedicated_pool_unavailable`），与本模式无关。模式对这类失败一律 fail-closed（`BLOCKED`，exit 9），不把 HTTP 200 或"提交成功"当 Accepted。
- 已解证据全部来自平台状态接口（`/me/solves`、`/qa/challenges`），不是提交返回码推断；flag 值只以 sha256 记录，不写入任何报告/笔记。
- 验收题目：`SAMPLE-005`（SAMPLE 套件，静态附件题）。Platform Playground 的 15 道题均绑定专用池，当前不可用；`dedicated_pool_unavailable` 原文为 "runs only on the machines reserved for this event"。
